# 小Lin说式横屏口播 · 自动分镜规则（STYLE_RULES）

> 适用：拿到定稿 A-roll（数字人/真人）+ SRT 之后，自动起草 `shotlist.yaml`；以后用 ChatCut 粗剪时也按这套规则下指令。
> 来源：只用 `ANALYSIS.md` 里有时间码证据的发现（证据编号 E1–E20）。没核实的不写进规则。
> **铁律优先**：本文件任何一条都不能覆盖 SKILL.md 第 0 节铁律。冲突时以铁律为准，本文件写明"按铁律"。

---

## 0. 先过三道闸（每一镜都要满足，引用铁律）

| 闸 | 规则 | 由谁拦 |
|---|---|---|
| G1 硬切/弱口型 | 每个硬切断点（±2 帧）和每句弱口型句**必须落在 broll / card / chapter 上**，不能是 person | 铁律 · `compile_shotlist.py` ERROR |
| G2 数字一致 | 屏幕上的数字必须和口播**原样一致**（"1万"就写"1万"，不许改成"10,000"）。参考片会换算单位（E12），**不照搬** | 铁律 · compile ERROR（已实测：把"8万"写成"80,000"会被拦下） |
| G3 素材许可 | 只用可商用来源，禁 ND/NC，每条登记 credits | 铁律 · compile ERROR |

另外保留铁律：16:9 1920×1080 24fps、音乐床约 -18 dB、成片 -16 LUFS / ≤ -1 dBTP、先 15 秒样片再逐章。参考片自己的响度（-13.9 LUFS，E18）**不照搬**。

## 1. 句子分类（从 SRT 文本自动判断）

按顺序匹配，先中先用（一句只归一类）：

| 代号 | 句型 | 判定条件（SRT 一条或相邻几条） |
|---|---|---|
| H | 开场钩子 | 片头前 1–3 条字幕（约 0–7 秒），以及紧跟着的"灾难/反差清单"串烧段（到第一次回到人物为止，参考片约 30 秒，E1–E3） |
| T | 术语/专有名词 | 含「叫做 / 号称 / 被称作 / 史称 / 也叫」+ 引号词或专有名词（E8、E9） |
| N1 | 单个主角数字 | 含数字+单位，且这句话**就是在讲这个数**（句子短 ≤14 字，或带「涨到/跌到/翻倍/倍/%/相当于」） |
| N2 | 数字序列 | 20 秒内出现 ≥2 个「年份/阶段 + 数字」，或在讲走势、排名、换算（E10–E13） |
| N0 | 路过的数字 | 有数字但句子重点不在数字上（多出现在串烧和故事里） |
| C | 对比 | 「A…而/但/可 B」「官方…黑市」「一边…一边」「相比」「不是…而是」（E14） |
| K | 因果链 | 25 秒内 ≥3 步「因为/就会/导致/所以/然后」（E7） |
| L | 后果清单 | 连续 ≥3 个并列短语（「进一步…/更多的…/更严重的…」或顿号列举）（E15） |
| S | 故事/例子 | 具体场景、人物、地点，「你看/比如/当时/有一次」 |
| Q | 设问/吐槽 | 「为什么呢 / 你说 / 怎么办呢 / 这谁受得了」 |
| E | 结论/观点 | 「所以说 / 其实 / 我觉得 / 说白了 / 总之」 |
| CH | 章节 | 「第X条/章」开头（沿用现有 build_shotlist 规则；参考片没有数字章节卡，见 E9） |

## 2. 决策树（句型 → 镜头）

```
句型 ──┬─ H 钩子
       │    ├ 第 1–2 句：person / wide / 不放面板 / trans: cut
       │    ├ 说出主题词那一句的开头：切 person / close（台阶推近，约 1.2 倍）            [E1, E4]
       │    ├ 主题词说完：card 主题卡 items=[m 英文/外文小字, b 主题词]，2.5–3.5 秒，
       │    │   压住下一句的开头（trans: sweep 或 cut）                                   [E1]
       │    └ 串烧段：broll 连切，每镜 0.8–1.6 秒；只在第一镜放圆形 pip；
       │        串烧里的数字按 N0 处理（只留字幕）                                         [E2, E3]
       ├─ T 术语：术语出口后 0–3 秒内切 card，items=[m 外文/拼音小字, b 术语]，停 1.5–3 秒，
       │        trans: cut；然后回人物                                                     [E8, E9]
       ├─ N1 单个主角数字：person / left 或 right，对侧 panel.chart = bignum，
       │        text = 口播原样写法，at = 这句字幕开头 +0.1 秒（不晚于数字本身被说出的时刻） [E12]
       ├─ N2 数字序列：card（模糊实拍底）+ chart：
       │        走势 → line（分两镜做"边说边画"，见 R-M3）；对比几年/几项 → bars（每根柱子 at = 该句开头）；
       │        排名 → bars，主角那根用 AMBER 或 CYAN，其余默认色；
       │        镜头 ≥4 秒时加圆形 pip                                                     [E10, E11, E13, E16]
       ├─ N0 路过的数字：不做图表、不做大数字，只靠字幕                                     [E3, E10]
       ├─ C 对比：person / left 或 right，panel.chart = compare（左右两栏各一个词）           [E14]
       ├─ K 因果链：≤3 步 → person / left|right，panel.items = p 词, a "↓", p 词, …, h 结果；
       │        每个词 at = 说到它那句的开头；>3 步 → card + items（同样逐个出现）+ 圆形 pip    [E7]
       ├─ L 后果清单：连续 card，每个短语一镜 1.2–1.6 秒，items=[m 修饰语, h 关键词]，
       │        负面词用 BAD 色；底图用暗化实拍                                             [E15]
       ├─ S 故事/例子：broll 段，每镜 0.8–2.1 秒，整段 4–16 秒；关键词中英文都写进 keywords  [E2, E5]
       ├─ Q 设问/吐槽：person / close（台阶推近），不放面板                                  [E4]
       ├─ E 结论/观点：person / wide，最多一个关键词 tags                                    [E4, E14]
       └─ CH 章节：chapter（沿用现有规则，trans: slam）
优先级：G1 硬切/弱口型 > 手势（必须人物镜头，铁律） > 上面的句型。
       某句被 G1 要求盖住时：句型是 N1/N2/C/K → 改用 card 版本；S/H/N0 → broll；T/L → card。
```

## 3. 具体参数

### 3.1 人物（person）
- R-P1 **居中优先**：参考片人物几乎永远在画面正中（检测到的人脸 95% 落在画面横向 49–52% 处，E4）。
  所以：**没有面板时用 wide / close（居中）**；**有面板时才用 left / right**（铁律要求的左右切换只在需要给图表让位时发生）。
- R-P2 人物镜头时长 2.5–6 秒（参考片人物段中位 5 秒，四分位 2.5–8 秒，E5；超过 6 秒按现有 WARN 拆成两镜）。
- R-P3 **台阶式推近**：参考片推近是一下子跳 1.14–1.2 倍，不是慢推，而且跳在新一句字幕的开头（E4）。
  做法：在 `aroll.presets` 把 `close.zoom` 设成 `1.2 × wide.zoom`；在新句开头切一个 `framing: close` 的 person 镜头，`trans: cut`。
  同一镜头里要再推一下：`push: {at: 句首, factor: 1.2, dur: 0.042}`（1 帧，等于跳切）。
- R-P4 手势镜头照现有规则：推镜关键帧放在手势起点（`push.dur: 0.6`），这条是铁律，不改成跳切。
- R-P5 全片人物占比 30–45%（参考片自动估计 33%，宽松估计 46%，E5）。

### 3.2 实拍（broll）
- R-B1 单镜 0.8–2.1 秒（参考片非人物镜头中位 1.33 秒，E5）；开场串烧 0.6–1.4 秒（E2）。
- R-B2 B-roll 成段出现（4–16 秒一段，E5），段与段之间回人物，不要人物/实拍一镜一换地交替。
- R-B3 B-roll 跟着字幕走：切点放在字幕句与句之间或逗号处（现有 build_shotlist 的切点候选就是这样）。
- R-B4 调色按铁律 navy；参考片里大量新闻画面、名人画面**不能学**（见 ANALYSIS「不要照搬」）。

### 3.3 图表 / 动效（card / panel）
- R-M1 数字出现时刻 = 包含这个数字的那句字幕的开头（+0.1 秒），不要等数字念出来才出（E12：「1万」那行在字幕开始的同一时刻出现）。
- R-M2 解释型图表镜头可以长（参考片一个换算动效连续 36 秒、一张油价图 12 秒，E11、E13），在本引擎里用 card 做（card 不触发 3.5 秒 WARN），但每 3–5 秒要有新元素出现（新柱子/新行/新词），否则拆镜。
- R-M3 走势图"边说边画"：本引擎 line 图只有一个出现时刻 → 拆成两镜：前一镜只放前半段点，后一镜放全部点（同标题）。
- R-M4 当前讲到的那一项高亮，讲过的变暗（E7 流程框：当前框淡黄底，旧框深色）。引擎里用 `h`（荧光笔）标当前项、`p` 标已讲项；bars 用单根柱子 color 标主角。
- R-M5 颜色语义：高亮/正在讲 = AMBER `#E8B060`，中性标签 = CYAN `#5FD3C9`，坏结果/下跌 = BAD `#E07A5F`。参考片 20:01 用粉紫色柱子 → 铁律禁粉色，不学。
- R-M6 双语小字：主题卡、术语卡、流程框可以在中文大字上方加一行外文/英文小字（`k: m`）（E1、E7、E8）。只是装饰，不能含数字。

### 3.4 画中画（pip）
- R-I1 按铁律"只偶尔用"：全片 pip 镜头 ≤ 镜头数的 10%（compile 的 WARN 线）。
- R-I2 优先放在：①开场串烧第一镜；②≥4 秒的全屏图表卡（card）。故事型 B-roll 不放。
- R-I3 位置/大小（按参考片量出，E6）：圆形左下 `pip: {x: 42, y: 682, d: 256}`；图表在左侧时放右下 `pip: {x: 1580, y: 640, d: 300}`。小窗底边不要低于 940 像素（字幕在 955 左右）。
- R-I4 参考片还用圆角矩形竖条小窗（E6）——**本引擎只有圆形，做不了**，记为 ChatCut/手工备注。

### 3.5 字幕
- R-S1 全程字幕，底部居中单行；`subs.max_chars: 14`（参考片每条中位 9 字、90% ≤14 字，E17）。
- R-S2 引擎字幕样式（62px 白字黑描边、底边 96px）已与参考片位置一致（中心约 955px），不改。

### 3.6 声音
- R-A1 按铁律：人声为主，音乐床约 -18 dB，整片 -16 LUFS / ≤ -1 dBTP。
- R-A2 主题卡（H3）期间人声停顿，可让音乐自然露出来（参考片片名卡处没有人声、背景声比说话段还响，E18）；只在这里加一个轻音效（`sfx.extra` 一条，-20 dB）。
- 音乐类型、音效种类：**未核实**（没有逐段人耳听辨），不写规则。

## 4. 节奏总表（自动起草时的目标值）

| 指标 | 目标 | 参考片实测（E5） |
|---|---|---|
| 平均切点密度 | 25–35 次/分钟 | 约 29 次/分钟（各分钟 9–57） |
| 人物镜头 | 2.5–6 秒 | 人物段中位 5 秒 |
| B-roll 单镜 | 0.8–2.1 秒 | 中位 1.33 秒 |
| B-roll 段 | 4–16 秒 | 中位 8 秒（非人物段，含图表） |
| 人物占比 | 30–45% | 33%（宽松 46%） |
| pip 镜头 | ≤10% 镜头 | 参考片更多（见 ANALYSIS E6，按铁律不跟） |

## 5. 套用示例（已实测通过编译）

曾用一段虚构的 30 秒深圳楼市口播，按第 2 节逐句套出 12 镜，仅作规则自测、不随本包发布：
H1 wide → H2 close 台阶推近 → H3 主题卡「深圳」→ H4 串烧 3 镜（首镜 pip，盖住 11.0 秒硬切，"30%" 按 N0 只留字幕）→ 人物 → T 术语卡「以价换量」→ N2 柱状图（8万 / 5.6万，每根在说到那句时出现，加 pip）→ Q close → K 因果链面板（供应变多 ↓ 库存上升 ↓ 价格往下走，手势起点推镜）→ E 结论 wide + 叠字。
`compile_shotlist.py --draft` 结果：0 error（只有素材 TODO 的提醒）；把「8万」改成「80,000」会报 ERROR（数字闸有效）。
注意：30 秒短样例人物占比 58%，偏高；整集按 R-P5 控制。

## 6. 做不到 / 只能手工或交给 ChatCut 的

| 参考片手法 | 证据 | 现状 |
|---|---|---|
| 人物居中、两侧各浮一张卡（左"汇率下跌"右"物价上涨"） | E14 | 引擎面板只能放一侧 → 用 left/right + compare 面板代替 |
| 圆角矩形竖条小窗 | E6 | 引擎只有圆形 pip |
| 一镜内连续多次台阶推近 | E4 | 一镜只有一个 push → 拆镜 |
| 走势线边说边延长 | E13 | line 只有一个出现时刻 → 拆两镜（R-M3） |
| 白色倾斜图表卡 | E10 | 引擎是深色玻璃卡；按现有 navy 风格，不改 |
| 片名卡淡入（溶解） | E1 | 没有 dissolve 转场 → 用 sweep 或 cut |
| 换算型数字（1万显示成 10,000） | E12 | 违反铁律数字一致 → 不做 |
