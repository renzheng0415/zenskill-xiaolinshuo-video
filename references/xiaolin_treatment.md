# 每期按选题定制画法

> 根据 howoneai/xiaolin-explainer-packaging 的 `references/treatment.md` 改写（MIT，Copyright (c) 2026 howoneai，见根目录 NOTICE.md）。
> **铁律优先**：硬切/弱口型必须盖住、屏幕数字与口播原样一致、只用可商用素材。这三条压过下面所有规则。
> 本文件讲的是「画面怎么设计」，不写口播稿，也不改镜头句型表（句型仍看 `xiaolin_style_rules.md`）。

## 1. 为什么要多这一步

本引擎的 `bignum` / `bars` / `line` / `compare` / `list` / `timeline` 只是骨架：管数字怎么排、什么时候出现。只换数字、不换画法，每期画面会长得一样，像套模板。

小Lin说原片里，家族样式是固定的（深色斜卡、白卡图表、文档荧光笔、章节卡），但背景和比喻是按选题变的：图形压在本期真实照片上，再用本期道具把意思做出来。合进来之后，每个图形场景在写进 `shotlist.yaml` 之前，先填下面这张表。

## 2. 画法设计表（精修镜头表之前先写）

写在项目的 `build/treatment.md`（或直接写在 `build/shotlist_review.md` 前面）。每个图形场景一行：

| 场景 | 覆盖哪几句 | 骨架（本引擎 kind/chart） | 背景（选题真实画面） | 道具和动作（选题隐喻） | 事实编号 | 硬切/弱口型是否盖住 |
|---|---|---|---|---|---|---|

写表时检查：

1. **每个图形场景都要有本期专属的东西**：选题照片、本期道具、真实 Logo 或官方页面截图，至少一样。只有骨架和数字的场景不合格，要补背景或改成人物+字幕。
2. **道具要承担意思，不能只做装饰**。拿掉它之后，意思变弱，才算选对了。例如：价格往上走，就让本期主体「爬」在折线头上；讲构成，就把一件实物按占比切开；讲关系，就用真实 Logo 当节点。
3. **相邻场景的画法不重样**。同一种动作（沿线走、切开、堆叠、流动、连续大数字）不要连用两镜。
4. 背景照片是底，不是主体：压暗、略虚化，主体仍是数字、图表和道具。许可必须可商用，禁 ND/NC，登记 `credits.json`。
5. 需要的资料先记到事实文件。查不到逐字原文或同口径数据，就换画法，不上假原文、不上拼出来的表。

本引擎暂时没有「道具骑在折线头上」「把照片切成饼图」这类专用槽位。做得到的，用 `card`/`broll` 的底图、叠字、对侧面板来近似；做不到的，写进 `build/shotlist_review.md`，需要时交给 ChatCut 路径，回来仍要过 `compile_shotlist.py`。

## 3. 和句型表怎么配合

先按 `xiaolin_style_rules.md` 给每句定句型，再给图形场景补画法，不要反过来（不要为了炫技巧改句型，更不要为了画法去改已经定稿的口播）。

| 句型 | 骨架仍按 3A | 画法上多做的事 |
|---|---|---|
| N1 单个主角数字 | person + `bignum` | 对侧或底图用本期相关实拍/照片，不要空海军蓝底配一个孤零零的数字 |
| N2 数字序列 | card + `line`/`bars` | 底图用本期场景；柱子/折线出现时刻仍 = 那句字幕开头；数字写法跟口播原样 |
| C 对比 | `compare` | 两侧各放能代表双方的真实画面或 Logo，不要只写两个词 |
| K / L 因果、清单 | 面板或连续 card | 每一步用一个能看懂的实物或截图，不要只堆文字胶囊 |
| T 术语卡 | card | 可配该事物的真实照片或 Logo；外文小字仍不能含数字 |
| S 故事 | broll 段 | 关键词中英文搜可商用实拍；不要用新闻图片社照片，也不要用别人视频的截帧 |

开场钩子、设问、结论仍然优先给全屏人物，不要全部盖上讲解画面。

## 4. 道具从哪来

- 优先用可商用实拍、Wikimedia Commons 照片、官方页面截图、真实 Logo（见 `research.md` 和 `scripts/commons_photo.py`、`commons_logo.py`、`web_shot.mjs`）。
- 需要专用透明道具时，可以另做 PNG，但必须在事实文件里标明来源或「AI 生成」；不要生成品牌 Logo，不要生成真人肖像，不要生成「好像是现场证据」的假照片。
- 同一期道具要像一套，不要一张卡通、一张实物照片混用。
- 本 skill 默认仍以可商用实拍为主，不把「AI 生成 B-roll」当成优先来源。
