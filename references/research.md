# 上屏资料怎么查、怎么记

> 根据 howoneai/xiaolin-explainer-packaging 的 `references/research.md` 改写（MIT，Copyright (c) 2026 howoneai，见根目录 NOTICE.md）。
> **铁律优先**：屏幕上的数字必须和口播原样一致；只用可商用来源，禁 ND/NC；每条素材登记 `credits.json`。
> 查不到的东西不上屏。事实文件是台账，不是口播稿。

## 1. 什么时候查

1. 按句型起草镜头表之后、精修之前，把每个图形场景要的资料列出来。
2. 逐条查到，写入项目的 `build/facts.md`（从 `templates/facts_template.md` 复制）。
3. 查不到逐字原文或同一口径的一组数据，就改画法：不用假报告页，不用拼凑对比表。
4. 台词里的数字和事实文件不一致时，**先改画面或改素材，不要擅自改已经定稿的口播**。定稿口播要改，必须先问用户。

## 2. 来源分级

| 级别 | 例子 | 能否上屏 |
|---|---|---|
| 一手 | 主管部门公报、政府文件原文、法规条文、交易所公告、国际组织数据库、项目所在地官方信息网的网签和项目数据 | 能 |
| 权威转述 | 权威媒体引用的一手数据 | 能，事实文件标「权威转述」。能找到一手时换成一手 |
| 推算 | 用一手数据自己算的比值、人均、合计 | 只有口播里也用同一写法时才能上屏。不要屏幕单独写「约」而口播没这样说。写清口径和算式；口播含糊就不上这个数 |
| 线索 | 自媒体、百科、论坛、销售口径、AI 回答 | 不能上屏。只用来找一手来源；找不到就列入「未验证」 |

补充：

- 地方数据用当地官方口径，不要拿全国或外地的数字当成当地的数字。
- 只在同一时间窗口、同一口径里做对比。
- 先看有没有更新年份的数据。还没公布的，不上屏，也不要在画面上「预估」。
- 事实文件记两个日期：来源发布日期、查阅日期。
- 演示或占位数据必须写明「示意数据」，不能混进正式成片。

## 3. 上屏写法

- 数字、单位、万/亿的写法，必须跟口播同一个样子。「1万」就写「1万」，不要改成「10,000」。
- 原文引用必须逐字，不改写、不把不同段落拼成一句。外文原文上外文，中文放字幕。
- 来源行写在图表或截图上（例如「来源：某某公报」），具体署名按许可写进发布文案。

## 4. 网页截图、照片、Logo

官方报道、公告、项目页，优先用真实截图，不要自己重排成「看起来像官网」的假页面。

网页截图：

```bash
source <skill>/scripts/env.sh
# 需要本机 Chrome，或 Remotion 自带的 headless Chrome
node $XL_SKILL_DIR/scripts/web_shot.mjs "<url>" $P/footage_raw/<名字>.png --w 1440 --h 1500 --wait 9      --boxes "要高亮的原文短语||另一句"      --blur "article img, figure img"
```

- `--boxes` 里的短语要和页面原文一致。拍完检查有没有 `MISSING`。
- 台词说的是某个时点的数字，去拍当时的页面（公开的历史存档可以；单页应用存档常是空白，拍出来空白就放弃截图，换画法）。
- 截图里的新闻图片社照片（Getty、AP、Reuters、视觉中国等）必须用 `--blur` 模糊，只用页面文字。
- 不要下载或裁切视频平台上别人的视频当素材，除非页面写明了可商用许可。
- 截图文件仍要进 `credits.json`（来源页、拍摄日期、许可说明），再经 `conform_footage.py` 入库。

照片（Wikimedia Commons，只收公有领域 / CC0 / CC BY / CC BY-SA）：

```bash
$XL_PY $XL_SKILL_DIR/scripts/commons_photo.py search "查询词" --n 6
$XL_PY $XL_SKILL_DIR/scripts/commons_photo.py get "File:<标题>.jpg" $P/footage_raw/<id>.jpg --width 2000
```

`get` 会同时写出 `<文件>.json`（许可、作者、页面、署名）。把署名抄进事实文件和 `credits.json`。也可以继续用本 skill 原有的 `fetch_footage.py`（Pexels、Pixabay、Mixkit、Wikimedia 等），规则不变。

Logo：

```bash
$XL_PY $XL_SKILL_DIR/scripts/commons_logo.py $P/footage_raw/logos "名称=File:Xxx.svg"
```

Logo 即使是公有领域文件，仍然可能是商标。只在讲到这个产品或机构时用来指代它；不改色、不变形，不排成好像在合作或背书，不放在封面和片尾当装饰。

## 5. 不要做的

- 不要编造报告原文、政策条文或数据。
- 不要用全国数字冒充某个城市的数字。
- 不要把销售口头价当成已公示的一房一价。
- 不要生成真实事件或真实人物的「证据照片」。
- 不要把未验证的条目画进图表。
