# 对方版式 → 本引擎怎么做

> 对照 howoneai/xiaolin-explainer-packaging 的版式库（MIT，Copyright (c) 2026 howoneai，见 NOTICE.md）。
> 本表只解决「想要那种画面时，用现有镜头怎么做」。不引入对方的 `scenes.py` API，也不换引擎。
> 铁律和 3A 句型表优先；这里选出来的版式还要再过画法表（`xiaolin_treatment.md`）。

| 对方版式 | 适用场合 | 本引擎做法 | 做不到时 |
|---|---|---|---|
| `bignum` 巨型数字 | 这句话就是在讲这一个数 | `person` 对侧 `chart.type: bignum`；`text` 用口播原样 | — |
| `wall` 卡片墙跟拍 | 2–4 个并列概念 | 连续 `card` + `items`，每张卡在说到时切过去 | 镜头在墙里平移、其余卡虚化：写进备注或 ChatCut |
| `paper` 白卡柱/条形图 | 几年对比、多项比较 | `card` + `bars`（深色玻璃卡，不改成白卡） | 白色倾斜卡已放弃，不要硬凑 |
| `docpage` 原文荧光笔 | 引用法规、公报、合同条款 | `web_shot.mjs` 截原文页当 `card`/`broll` 底，叠字写出要强调的句 | 逐行刷荧光笔：备注或 ChatCut |
| `webshot` 真实网页 + 聚光 | 报道、官网、公示页 | 同上，截图入库后当背景；图片社照片必须模糊 | 聚光跟随滚动：备注或 ChatCut |
| `logo` 真实 Logo | 讲到具体产品或机构 | `commons_logo.py` 取图，放进 card/面板/实拍叠层 | 没有专用 Logo 片组件 |
| `ent6` 实体卡 | 国家、公司、机构名片 | `card` + `items`（大名 + 一行事实） | 国旗章样式没有，不生造国旗 |
| `formula6` 大公式条 | 分步公式、因果链 | ≤3 步用人物对侧面板（词 → 箭头 → 结果）；>3 步用 `card` | 整条公式横条：备注 |
| `ui` 白底计算器 | 「如果你……会怎样」测算 | 暂无 | 备注或 ChatCut；上屏数字仍须与口播一致 |
| `line6` 分段画线 | 走势、涨跌 | `line`，按风格规则拆成两镜「边说边画」 | 道具骑在线头上：备注 |
| `timeline6` 时间轴 | 沿革、节点 | `chart.type: timeline` | 镜头沿轴平移：能近似就近似，否则备注 |
| `pie6` 饼图/环形图 | 构成、占比 | 暂无饼图组件 | 改用 `bars` 或清单；真正的环形切开图走备注/ChatCut |
| `flow6` 流程/循环 | 步骤、产业链 | 因果链面板或连续 card | 回环箭头：备注 |
| `tree6` 树状拆解 | 一项拆成几项 | 连续 card 或清单 | 树形分支：备注 |
| `map6` 地图航线 | 产地、路线、分布 | 暂无 | 涉及中国疆域时，不用对方世界示意图，改用有审图号的标准地图或不用地图 |
| `vs6` 左右对比 | 两方对比 | `compare` 面板；两侧尽量配真实画面或 Logo | 全屏大卡 VS：备注 |
| `graph6` 关系/资金流 | 持股、流向 | 暂无 | 备注或 ChatCut |
| `stack6` 象形图网格 | 「每 100 个里有多少」 | 暂无 | 用数字+清单近似，或备注 |
| 片名/章节/片尾卡 | 章节切换 | 已有 `chapter`；封面走 `cover.py` | 默认不加片尾署名卡（铁律）；溶解转场没有，用 sweep 或 cut |

选版式时再加两条：

- 同一个骨架不要连续用两个镜头以上（不要连着三张大数字卡）。
- 每个图形场景至少有一样本期专属的东西，见 `xiaolin_treatment.md`。
